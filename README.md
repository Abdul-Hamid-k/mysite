# MySite

**MySite — Site Manager** is an offline-first app for tender contractors: expenses, party dues, labour and machinery attendance, material stock and planning, and site profit, for Android and Windows. It works without internet and syncs when you are online. Available in English, Hindi, Marathi, Gujarati, Tamil and Telugu.

This repository only holds the **downloads**. Get the latest version from the [Releases page](../../releases).

## Install

- **Android:** download the `.apk` from the latest release, open it on the phone, and allow installs from this source when asked.
- **Windows:** download the `.zip`, unzip it, and run `mysite.exe` from inside the unzipped folder.

## Status

Current builds are **preview versions** for testers. They connect to a test server, and sign-in codes are only sent to approved test email addresses for now, so a new account may not be able to register yet. Please do not rely on a preview for real business records.

Each release lists SHA-256 checksums so you can check a download.
